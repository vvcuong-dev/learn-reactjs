# Thao tác với API trong ReactJS

## Các phương thức để thao tác với API

- fetch API
- thư viện axios

## Server API

- Sử dụng các dịch vụ fake api, mock api,...
- thư viện json-server

## Quy trình thao tác với API

1. Gửi yêu cầu đến server API => xác định được call API ở đâu, khi nào và dữ liệu gửi đi là gì (componentDidMount, event Handler, useEffect,...)
2. setState dữ liệu nhận được từ server API
3. RenderState dữ liệu lên giao diện
4. Cập nhật trạng thái của component
